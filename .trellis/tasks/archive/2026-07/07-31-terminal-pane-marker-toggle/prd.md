# 终端状态标记默认关闭开关

## Goal

在“设置 → 终端状态标记”中新增持久化开关，默认关闭；用户显式开启后继续使用现有焦点与 Hook 状态标记行为。

## Requirements

- `TerminalPaneMarkerSettings` 增加 `enabled: boolean`，默认值为 `false`。
- 缺少 `enabled` 的旧配置和非法值均迁移为关闭，已有用户升级后同样默认关闭。
- 关闭时不渲染任何终端状态标记，但保留样式与颜色偏好。
- 设置页显示中英文开关；关闭时样式和颜色控件保持可见但不可操作。
- 默认焦点标记使用当前终端的弱化色与背景色混合，避免固定高饱和颜色过于突兀。
- 顶部标记的左右竖线高度为终端内容区的 `2%`，完整边框样式保持全高。
- 继续通过现有 `terminalPaneMarker` 偏好项持久化和同步，不新增依赖、数据库或后端接口。
- 更新前端契约、功能清单与 `[TEMP]` 变更日志。

## Acceptance Criteria

- [ ] 缺失、旧版或非法 `enabled` 值均归一化为 `false`，显式 `true` 保留。
- [ ] 开关关闭时，焦点、完成、错误、审批状态在任何分屏/窗口状态下均不显示标记。
- [ ] 开关开启时，现有标记样式、颜色、焦点和 Hook 状态优先级保持不变。
- [ ] 开关值重启后持久化，并继续参与偏好同步。
- [ ] 中英文文案完整，关闭状态下从鼠标和键盘均不能修改下级控件。
- [ ] 深色、浅色和自定义终端主题下，焦点标记自动跟随终端配色；Hook 状态色和自定义颜色不变。
- [ ] 顶部标记运行态与设置预览的左右竖线均为 `2%`，完整边框不受影响。
- [ ] 状态标记、Workspan、Hook 绑定测试及 TypeScript 类型检查通过。

## Changelog Target

`[TEMP]`

## Notes

- 用户已确认旧配置升级后也默认关闭。
- 不修改终端布局、Hook 状态来源、颜色优先级或 Rust 后端。
